# Coalition Patient Dashboard

## Project Overview
A responsive patient dashboard developed using HTML, CSS, and JavaScript.

## Features
- Patient information display
- Patient dashboard interface
- Vital signs visualization
- Patient data integration using API
- Interactive dashboard design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
- REST API

## Installation
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
